# pairwise-csm-seams

同一面墙在两级级联交界处裂出一条硬阴影缝，级联划分按视锥体积均分，近处 texel 密度和远处差四倍；级联选择用相机距离硬切，走过去阴影突然换层；pancaking 没做，贴墙物体的阴影被挤没；阴影偏移按固定 texel 世界尺寸算，远级联 acne 大面积出现；动态物体只更新第一级，远处角色没有影子；级联包围球没随相机旋转收紧，边缘物体落在图外；PCF 与 ESM 在不同级联混用，半影像素化方块；阴影数组层采样偏移写死，换分辨率后整体偏一格；远景级联更新频率低，路灯影子周期性闪烁；半影宽度没随级联缩放，交界处一边锐一边糊。render/csm_seams.py 是核心，tests/test_csm_seams.py 15个红。要修的是：级联按屏幕误差划分；级联切换加滞回；pancaking 按光方向压扁；偏移按各级联 texel 世界尺寸；动态物体逐级更新；包围球按相机朝向收紧；滤波核统一；层偏移按分辨率换算；远级联加时间抖动；半影按级联缩放。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
